# メール送信でファイルをDriveへ自動整理する仕組み

写真やPDFを **メールで送るだけ** で、Google Drive の適切なフォルダへ自動で振り分けて保存する仕組みです。
LINE公式アカウントは不要。新しいアプリも不要。**すべて無料** で作れます。

```
スマホ/PCでファイルを「共有 → メール」で専用アドレスへ送信
                     │
                     ▼
      Google Apps Script が15分ごとにメールをチェック
                     │
                     ▼
   添付ファイルを種類ごとに Drive のフォルダへ自動保存
                     │
                     ▼
        「◯件保存しました」とメールで通知（任意）
```

---

## 必要なもの

- 普段使っている **Googleアカウント（Gmail + Drive）** … これ1つだけ
- ここにある `Code.gs`

---

## セットアップ手順（10分ほど）

### ① Google Apps Script のプロジェクトを作る
1. パソコンで <https://script.google.com/> を開く
2. 「**新しいプロジェクト**」をクリック
3. 左に出てくる `コード.gs`（または `Code.gs`）を開く

### ② コードを貼り付ける
1. このリポジトリの [`Code.gs`](./Code.gs) の中身を **全部コピー**
2. Apps Script のエディタに **上書きで貼り付け**て保存（💾 or Ctrl+S）

### ③ 自分用に設定を調整（任意・あとでもOK）
`Code.gs` の上のほうにある `CONFIG` を必要に応じて書き換えます。
最初はそのままでも動きます。

| 設定項目 | 意味 | 初期値 |
|---|---|---|
| `ROOT_FOLDER_ID` | 保存先を既存フォルダ（会社の共有ドライブ等）にしたい場合のフォルダID | 空（＝マイドライブに作る） |
| `ROOT_FOLDER_NAME` | 保存先の親フォルダ名（`ROOT_FOLDER_ID`が空のときだけ使う） | `自動整理ボックス` |
| `RULES` | どのファイルをどのフォルダに入れるかのルール | 請求書 / 写真 / PDF書類 など |
| `NOTIFY_SUMMARY` | 保存後に自分へ通知メールを送るか | `true` |

#### 会社の共有ドライブに保存したいとき

1. ブラウザで、保存先にしたい**共有ドライブのフォルダを開く**
2. アドレスバーのURLを見る:
   `https://drive.google.com/drive/folders/`**`1AbC...xyz`** ← 末尾のこの部分がフォルダID
3. そのIDをコピーして `Code.gs` の **`ROOT_FOLDER_ID`** に貼る:
   ```js
   ROOT_FOLDER_ID: '1AbC...xyz',
   ```
4. 保存すれば、以降はその共有ドライブフォルダの中に振り分け保存されます。
   （振り分け用のサブフォルダ「写真」「PDF書類」等はその中に自動で作られます）

> **注意**: 共有ドライブに保存するには、あなたがそのフォルダの**「編集者」以上の権限**を
> 持っている必要があります。権限が無い場合は実行時にエラーになります。

> **振り分けを増やしたいとき**は `RULES` に1行足すだけです。例:
> ```js
> { folder: '名刺', keywords: ['名刺', 'card'], extensions: [] },
> ```

### ④ 自動実行をONにする（初回だけ）
1. エディタ上部の関数選択メニューで **`setupTrigger`** を選ぶ
2. 「**実行**」ボタンを押す
3. 初回は「**承認が必要です**」と出るので、
   - 「権限を確認」→ 自分のGoogleアカウントを選択
   - 「詳細」→「（安全ではないページ）に移動」→「許可」
   - ※これは自分で作った自分用スクリプトなので問題ありません
4. 実行ログに「自動実行トリガーを登録しました」と出れば完了

これで **15分ごとに自動でメールをチェック** するようになります。

### ⑤ 動作テスト
1. 自分のGmail宛に、**適当な写真かPDFを添付してメール送信**
2. 数分待つ（すぐ試したいときは `processIncomingMail` を手動実行）
3. Drive を開き、`自動整理ボックス` の中に振り分けられていればOK 🎉

## 使い方（日常）

スマホの写真やファイルを開き **「共有」→「メール（Gmail）」** で自分のアドレスへ送るだけ。
あとは自動でDriveに整理されます。

> ### さらにラクにするコツ
> - **専用アドレスにしたい**場合は、Gmailの「+エイリアス」が便利です。
>   例: `あなた+files@gmail.com` 宛に送り、`CONFIG.SEARCH_QUERY` を
>   `'is:unread has:attachment to:あなた+files@gmail.com'` にすると、
>   普段のメールと混ざりません（Gmailは `+○○` を付けても本人に届きます）。
> - iPhoneなら「共有」先にGmailやメールでこのアドレスをよくつかうVIPに入れておくと一瞬です。

## 仕組みの補足

- **二重保存されない**: 処理済みのメールには `ファイル整理済み` ラベルが付き、次回以降スキップされます。
- **同名ファイル**: 同じフォルダに同名があれば `写真 (1).jpg` のように自動で番号が付きます。
- **完全無料**: Apps Script も Gmail も Drive も無料枠内で動きます（個人利用なら十分）。
- **止めたいとき**: Apps Script の「トリガー（時計アイコン）」画面から削除すれば停止します。

## よくある質問

**Q. 会社の公式LINEや会社アカウントに影響する？**
A. しません。この仕組みは指定したGoogleアカウント内だけで完結します。

**Q. 送ったメール本文も保存される？**
A. いいえ、**添付ファイルだけ** を保存します。本文は保存しません。

**Q. AIで賢く振り分けたい**
A. まずはこのルール方式で運用し、迷うファイルが増えてきたら Claude API を使った
   AI判定を後から足せます。必要になったら相談してください。
