# DESIGN.md — GIFT COMPASS（ギフト・コンパス）

彼への誕生日プレゼントに迷う女性のための、**トレンド解説＋診断で最適な複数候補を提示する**まとめサイト。

---

## 1. コンセプト

> 「あなたと彼の関係から、贈るべき一つ」を、迷いなく。

- **対象ユーザー**: 20〜60代の女性。恋人・夫・父・上司・友人など、男性への誕生日プレゼントに迷っている。
- **提供価値**:
  1. **最新トレンド（2026）** をキュレーションして俯瞰できる
  2. **診断フォーム**（年代 / 関係性 / 職業タイプ / 予算 / こだわり）に答えると
  3. **複数の最適候補**を「選ばれた理由」つきで提示する
- **トーン**: 上品・編集的（マガジン風）。ギャルっぽさや過剰な装飾を避け、大人の女性が信頼できる静けさ。

---

## 2. 美学プロンプト（Claude Cookbook "aesthetic" 原則の適用）

Anthropic Cookbook のデザイン原則を本サイトの具体指針に翻訳する。

| 原則 | 本サイトでの実装 |
|---|---|
| **Restraint（引き算）** | 装飾を足さず、余白で語る。影・グラデは最小限。1アクセント色のみ。 |
| **Typographic hierarchy** | 見出しはセリフ大サイズ、本文はサンセリフ。サイズ・字間・色の三段でメリハリ。 |
| **Generous whitespace** | セクション上下 `clamp(80px,12vw,160px)`。要素間も広く取り「呼吸」させる。 |
| **Intentional color** | 白ベース＋温かみのある1アクセント（テラコッタ）。色は意味のある箇所にだけ。 |
| **Content-first** | 装飾より情報設計。診断は3ステップで迷わせない。 |
| **Consistency（システム化）** | 間隔・角丸・色をCSS変数に統一。全セクションが同じ文法で並ぶ。 |
| **Motion with purpose** | スクロールで静かにフェードイン。派手なアニメは使わない。 |

## 3. デザイントークン

```
--bg:        #FBFAF7   /* 白ベース（わずかに温かい） */
--surface:   #FFFFFF
--ink:       #1C1917   /* 見出し・本文（ほぼ黒） */
--ink-soft:  #57534E   /* 補助テキスト */
--line:      #E7E2DA   /* 罫線・境界 */
--accent:    #B4553D   /* テラコッタ（唯一のアクセント） */
--accent-soft:#F4E9E3  /* アクセントの淡色背景 */
--gold:      #A8792C   /* 見出し装飾の差し色（控えめ） */
```

**タイポグラフィ（文字大きめが要件）**
- 見出し: セリフ体（Georgia / "Times New Roman" 系のシステムフォント）
- 本文: システムサンセリフ（游ゴシック / Hiragino / system-ui）
- スケール:
  - Hero H1 `clamp(44px, 8vw, 92px)`
  - Section H2 `clamp(30px, 5vw, 52px)`
  - 本文 `clamp(17px, 1.6vw, 20px)` / 行間 1.9（大きめ・読みやすさ最優先）
- 角丸: `--r: 4px`（シャープで上品）/ カード `12px`

## 4. 情報設計（セクション構成 = 実装単位）

Claude Code でこの順に**セクション単位**で実装する。

1. **Header** — ロゴ「GIFT COMPASS」＋ナビ（トレンド / 診断 / 一覧）
2. **Hero** — キャッチ＋サブ＋「診断をはじめる」CTA。白背景に大きな文字。
3. **Trends 2026** — 今年の贈り物トレンド3〜4本をカード解説（体験型 / サステナブル / スマートガジェット / ご褒美消耗品）
4. **How it works** — 3ステップ（答える→分析→複数提案）
5. **Diagnosis（診断フォーム）** — 年代・関係性・職業タイプ・予算・こだわり(複数選択)
6. **Results（結果）** — スコアリングで上位候補を複数枚、「選ばれた理由」タグ付きで提示
7. **Gift Catalog** — 全アイテム一覧（フィルタの母集団）
8. **Footer** — 注意書き・クレジット

## 5. 推薦ロジック（クライアントサイド・スコアリング）

各ギフトに属性タグを付与し、フォーム回答との適合度でスコア化 → 上位を提示。

- 入力: `age`（20-60代）, `relation`（恋人/夫/父/上司・同僚/友人・兄弟）, `job`（ビジネス/クリエイティブ/アウトドア/インドア/経営者）, `budget`（予算上限）, `interests[]`（ガジェット/ファッション/お酒/健康・運動/コーヒー・食/リラックス）
- スコア = 関係性一致(×3) + 年代一致(×2) + 職業一致(×2) + 興味タグ一致(×2/件) + 予算内(+3, 超過は除外) + トレンド加点(+1)
- 出力: 上位4〜6件。各カードに「選ばれた理由」を最大3タグ表示。0件時はフォールバック提案。

**セキュリティ**: フォーム値は固定選択肢のみ（自由入力の相手情報はDOMに`textContent`で挿入し、`innerHTML`を使わない）。外部送信・保存は行わない（完全にローカル完結）。

---

## 6. アクセシビリティ / 品質チェック

- 文字コントラスト AA 以上（ink/bg = 十分）
- フォーム要素は `<label>` 関連付け、キーボード操作可
- レスポンシブ（モバイル1カラム / PC多カラム）
- `prefers-reduced-motion` でアニメ無効化
- 画像アセット不使用（CSS/絵文字/インラインSVGで自己完結）
